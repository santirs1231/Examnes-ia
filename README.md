# SIAD-Saber Pro

Sistema de apoyo académico para organizar información curricular y crear, guardar y gestionar evaluaciones.

## Requisitos

- Node.js
- Variables de entorno de Supabase configuradas en `.env` o `.env.local`

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Validación y producción

```bash
npm run lint
npm run build
npm run start
```
